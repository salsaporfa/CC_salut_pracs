Finally for the rest of the variables, we choose Predictive Mean Matching (the default setting for numeric variables) as the imputation method\\

As before, this search strategy will not be exhaustive, and achievement of the global optimum is not guaranteed.One possible search strategy is a backward sequential selection algorithm, which would work as follows (17). For the number of clusters k = 2, …, kmax, where the maximum number of clusters is fixed a priori, the algorithm starts  with a set of selected variables containing all variables and an empty set of  removed variables. The k-means algorithm is run excluding one of the variables in the selected set at a time. The variable that, when excluded, provides a higher value of CritCF is removed from the set of selected variables and added to the set  of removed variables. The process keeps iterating until none of the selected variables brings any improvement in CritCF when excluded. The combination of k and the set of variables that gives a higher CritCF is chosen as the final model.


\section{Report}

The multiple imputation cluster analysis was performed on 342 with 45 variables participants using 100 imputed datasets. The final solution consisted of two clusters, as supported by Figure~\ref{fig:figura1}. The two-cluster solution achieved consistently higher CritCF values than the three-cluster solution, with a median of approximately 0.553 compared with 0.525. Furthermore, the relatively small variability of CritCF for $k=2$ suggests that the selected number of clusters is reasonably stable across imputations. The final cluster sizes and their uncertainty remain to be reported.

Relabelling the clusters across the imputed datasets is necessary because cluster labels are arbitrary and may differ between imputations. The degree of agreement after relabelling should be evaluated to determine whether the same underlying groups are consistently identified. The corresponding agreement statistics are not yet available in the reported results.

Regarding variable selection, the backward search procedure
was applied to identify the variables contributing most
strongly to the clustering structure. As shown in
Figure~\ref{fig:figura2}, the selected variables included
\texttt{fevp\_postv1}, \texttt{rv\_prepv1},
\texttt{vas2\_v1}, \texttt{iam\_chv1},
\texttt{graudisn\_v1}, and \texttt{cil8\_s\_mv1}.
Their selection frequencies provide information about
uncertainty: variables repeatedly selected across imputations
are more stable, whereas variables with lower frequencies
are more sensitive to the imputed values. The exact final
subset and its selection frequencies should be confirmed
from the clustering summary.

Finally, cluster membership probabilities allow the
uncertainty associated with participant classification
to be assessed. Probabilities close to one indicate
strong evidence of membership in a particular cluster,
whereas probabilities close to 0.5 suggest ambiguous
classification in a two-cluster solution. These probabilities
should be summarized for each cluster, together with their
variability across imputations.

Overall, the analysis supports a two-cluster structure,
although the stability of cluster membership and the
uncertainty in cluster sizes and assignment probabilities
require further numerical assessment.
